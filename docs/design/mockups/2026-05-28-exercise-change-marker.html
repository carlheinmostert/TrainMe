Exercise change marker

Surfacing "this exercise has edits not yet published" on Studio exercise cards. Three visual options — same data signal (exercise.lastEditedAt > session.sentAt).

Option A — coral left-edge spine

A 4px coral bar runs the full left edge of any card with unpublished edits. Reads as "this row is dirty" at a glance; scales to a list (you see a column of coral spines for everything you've touched). Doesn't steal content space.

Behaviour (all options)

  • Marker shows when exercise.lastEditedAt is after the session's last publish (sentAt).
  • All markers CLEAR the moment the session is published (publish stamps a new sentAt; every exercise's edit time is now older).
  • A never-published session: no markers (nothing to compare against — the whole session is "new", surfaced by the Publish CTA, not per-card).
  • Newly-added exercises on an already-published session DO get the marker (their lastEditedAt > sentAt).
  • Open question: does reorder (position change) count as an edit for the marker? Proposed: NO — position changes are structural/session-level, not per-exercise content. Marker = content edits only (reps/sets/hold/notes/trim/treatment/body-focus).
