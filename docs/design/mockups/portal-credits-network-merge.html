/credits page top — what you see when you click in

Once Network leaves the dashboard, its full UI (rebate balance, network roster, share code, payout history) needs a home. The cleanest move: keep the existing /network page but link to it from a prominent banner at the top of /credits. Practitioners arriving via either path land somewhere coherent.

RECOMMENDATION

Go with Variant A on the dashboard tile + the banner at the top of /credits. The band reads as one coherent "currency widget" (paid + free, one card) while still telegraphing that earning is a separate path. Variant B is too subtle for an under-used feature — Carl already raised that earning needs more presence. Variant C tries to do too much in one headline and risks the 8 + 0.4 = 8.4 misread. The freed dashboard slot becomes the Classes "Coming soon" tile per item C-9, restoring the 3-up grid without an awkward hole.
