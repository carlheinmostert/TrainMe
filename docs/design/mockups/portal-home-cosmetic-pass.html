What this mockup encodes

1
Lockup top-left at h-10. Wordmark stacked above the matrix, exact-width via textLength="48". .studio (with the dot) renders coral #FF6B35; homefit stays light #F0F0F5. Same rule applies on mobile + web player + auth emails + OG card in this wave.
2
Right side: two-line identity stack. Top line = literal email. Bottom line = practice name with a chevron that opens the switcher popover (chevron hidden if user is in one practice only). Below both: small Sign out text link. No chip, no dropdown, no rename inline — rename lives on /account.
3
No "Dashboard" h1. The route stays at /dashboard — only the user-visible label is gone. Browser tab title drops the word too. Same header chrome ships on every authenticated page (Clients, Audit, Members, Network, Credits, Account).
4
Tile order: Credits · Network · Clients · Audit · Account · Members. Credits + Network adjacent (currency cluster, per the existing comment in dashboard/page.tsx:205-211). Account second-to-last. Members owner-only.
5
Every tile gets a 40px left icon slot. Lucide outline icons, 1.75 stroke, 24px. Muted-ink at rest, coral on hover (matches existing chevron behaviour). The Audit card is treated identically — icon on left, audit rows shift right of the slot.
6
Hover popover, 400ms delay (Radix Tooltip). Floats above the tile with a downward caret. Touch viewports: (i) info glyph in the top-right of each tile opens the popover on tap. Tile click target intact — popover doesn't intercept.
7
Account is now a tile, not a dropdown. The chip's dropdown is gone — Sign out moved to the header text link, Account settings moved to the tile. The chip itself collapses into the text-style identity stack.
8
Mobile: header stays one strip. Lockup shrinks to h-8, email wraps below "Signed in as" label, practice name truncates on extreme narrow widths. Tiles stack to one column with info glyphs surfaced (no hover on touch).
