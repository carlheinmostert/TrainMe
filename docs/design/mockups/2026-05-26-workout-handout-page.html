Anatomy

Surface anatomy

Brand area — top-left: practitioner identity. Today: homefit.studio lockup + plan title + "from {Name} · {Practice}". This is where the brand-skin sits when subscribed (~2 cr/mo): practitioner logo + accent colour replace the default homefit look here, but the footer seal stays.
Print / Save as PDF — top-right icon-button. Triggers the browser's native print dialog; the page's @media print stylesheet hides the claim chip + treatment toggle (they're uninteractable on paper) and lays out the exercise list cleanly. Print is a button on the page, not a separate artifact.
Claim chip — coral-tinted, dismissible. Quiet first visit; escalates on return (subtle pulse on third visit, never a modal/wall — R-01). Tap → magic-link sign-in; the page already knows its plan_id so signup attaches the plan to the new account.
Treatment toggle — segmented control directly above the list. Coral-active. Switches the hero thumbnails instantly (CSS filter for B&W against the same source; src swap for Line).
Exercise list — compact, scannable, printable. Numbered hero thumbnails + name + reps/sets/hold + practitioner notes. Circuits read as a coral-bordered group with a "Circuit · N rounds" header so the structure survives the static format.
Footer seal — "powered by homefit.studio" mark + QR + version stamp. Coral-tinted, designed as a credibility seal (not a banner ad). The version stamp ("v3 · 26 May 2026 14:32") survives onto print so a printed copy is traceable to a specific publish.

Claim chip behaviour

First visit — quiet. Coral-tinted strip, no animation, scrolls with the page. The patient with a sore knee can ignore it entirely and just do the exercises.

Return visits — escalates. Second open: same chip, no change. Third open onward: a subtle one-second pulse on landing draws the eye. Never becomes a banner across the top, a sticky footer, an interstitial, or a modal. R-01: no popups, ever.

Dismissible. The "X" closes the chip for this session (localStorage flag; reappears next visit at the current escalation level). Long-term dismiss happens by claiming — once they have an account, the chip is replaced by an "Open in My Workouts" link.

Magic-link only. No password, no OAuth (Apple/Google deferred). Tap → email field → "Check your inbox" → done. Lowest possible friction for the low-tech / older-patient crowd.

Treatment + consent

Line is always available. The de-identification happens in the conversion pipeline, not the consent layer — consent can't be withdrawn from line drawings because there's nothing identifying to withdraw.

B&W and Original are consent-gated. The practitioner-toggled video_consent on the client row decides which segments are unlocked. In this mockup: B&W consented, Original not — the Original pill renders muted with a lock glyph; tap it and a tooltip reads "your practitioner hasn't enabled this for sharing."

Same surface, same rules. The handout honours treatment + consent exactly like the workout player — no "higher bar for print," no static-only line lock. This was a locked decision (#10).

The seal is permanent and tri-party

homefit is never white-labeled away. Even on a fully brand-skinned handout, the footer keeps the "powered by homefit.studio" mark + QR + version stamp in homefit coral. This is the deal: the practitioner's logo gets pride of place in the header (the brand-skin), homefit gets the credibility seal in the footer.

Client/patient — the seal reads as a credibility signal: "my practitioner runs on a real, auditable system." Like an "as seen on" trust mark.

Practitioner — the seal makes them look more serious, not less. Their own logo plus a credible platform mark is the professionalism they're paying the skin subscription for.

homefit — the permanent funnel. The QR carries ?ref={code} as link attribution — the referral code is in the URL the recipient lands on, never the QR's destination (the recipient always lands on their plan, not a signup page). This means the seal can earn the practitioner referral rebates, which is the strongest reason they're happy to keep it.

Version stamp. "v3 · 26 May 2026 14:32" — small, ink-muted. Prints with the page so a printed copy traces back to a specific publish. The artifact is live, but a printed sheet is frozen — the stamp tells you when it froze.
