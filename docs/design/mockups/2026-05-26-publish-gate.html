Anatomy

Row states

Available · unchecked — neutral surface, plain border. Tapping anywhere on the row toggles it. Nothing is pre-checked, even free rows.
Available · checked — coral checkbox, coral-tint card background, coral border. The card itself reads as "selected" so the state is unmissable while you scan the list.
Live — already minted from an earlier publish. Sage-green border, "Live" pill next to the name, no checkbox toggle. Re-ticking is a no-op, never a re-charge.
Soon — the format is in the registry but not shipped. Muted, non-tappable, "Soon" chip. When the type lights up globally, the row becomes Available with no UI change anywhere else.

Price column

Free Free (0 cr) — the workout handout is the only free artifact today; poster + calendar are free / TBD. Shown explicitly so a free row reads as a deliberate choice, not an oversight.
1 Paid (1–2 cr) — the workout player; 1 credit if plan ≤ 75 min, 2 credits otherwise (ADR 0007). The price is locked once shown — the duration estimate happens before the sheet opens.
TBD Premium TBD — reels / ai_reel placeholder once they ship. The TBD label is honest while the price is being decided.

Running total + CTA

Total = sum of checked rows. Coral, large, in the heading-typeface — the cost is the headline of the foot, not an afterthought. Updates live as rows are ticked.

Balance line above. Small, dashed-underline separator. Confirms credits-on-hand and the duration-tier read so the practitioner doesn't have to leave the sheet to check.

CTA states what it'll do. "Publish 2 artifacts · 1 credit" beats "Publish" or "Confirm" — no surprise after the tap. Greys out when nothing is checked.

Why this shape

One transaction, atomic. Confirm sums the checked paid kinds, calls consume_credit once for the total, and upserts every plan_artifacts row in the same DB transaction (alongside plan_issuances). Materialised-render failure (reel transcode) triggers a compensating refund.

Always-on registry. A new artifact type (poster, calendar) ships once globally and lights up here for every plan automatically — no per-plan migration, no opt-in.

Re-opening is safe. The gate is also the "publish more" view; Live rows lock; new rows are tickable. No re-publish path exists — edits flow live to every minted artifact already.
