What's different vs. the shipped version

  • Live transparency view surfaces at the page level (top action bar). It's practice-wide — every premises in this list shares the same /v/{slug}/now URL — so a single prominent entry point makes sense. The per-row Live button is also there as a familiar in-row affordance for owners who scan row-by-row.
  • Poster download moves out of the Edit form and onto each row directly. Only shown for Safe Mode enforced rows (a non-enforced premises has no bystander-trust artefact to print).
  • Edit / Delete are visually separated from the public actions by a thin vertical rule, so practitioners can scan public-vs-private intent quickly. Edit stops being a gateway to public resources.
  • If the row becomes cramped on mobile, the public actions group ( Live + Poster ) collapses to a single overflow button. Edit / Delete stay visible.
