Icon explorations

All in coral. Designed to read at 16px (banner) AND 64px (about / settings). Stroke widths chosen for legibility at the small size.

1. Shield + Person
"Protection over a person." Most literal of the bunch.
14px banner size
2. Subject + obscured bystander
Two figures: one solid (client), one dashed (bystander obscured). Most literal to what the feature DOES.
14px banner size
3. Protected sight
Eye + shield wedge. Reads as "we control what's seen." Could feel surveillance-y if drawn wrong.
14px banner size
4. Coral silhouette
The icon = what the feature actually renders. Self-explanatory after first exposure. Simplest at small sizes.
14px banner size

How to read this mockup

  • The top phone shows the current build banner (what Carl saw on his iPhone today) for comparison. Tiny, easy to miss.
  • Variants A / B / C are three directions, all coral-saturated. A is single-line; B adds an explanatory sub-line; C uses pulse to draw the eye without claiming as much screen space.
  • Icons 1–4 are four directions for the Safe Mode visual identity. Each card shows the icon at 64px (about / settings size) plus a 14px miniature for how it'll read inside the banner.
  • The icon you pick gets embedded into the banner you pick + becomes the Safe Mode glyph on per-exercise chips in Studio + on the audit feed.
  • Reply with Banner X · Icon N (e.g. "Banner B · Icon 4"). We can also iterate on the picked pair to refine.
