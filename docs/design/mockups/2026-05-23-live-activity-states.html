Content state contract

  • Attributes (immutable): sessionId, practiceId
  • Content state (mutable): clientName, clientInitials, avatarFilePath (App Group container), captureCount, lastCapturedName, safeModeActive, sessionTitle
  • Updates fire on: capture completed (count++ + lastName), Safe Mode flip (debounced 5s), publish (then end), session-shell exit (end)
  • Tap target: entire card + the "Capture next" button → OpenCameraIntent App Intent (iOS 17+) or defaultLaunchURL (iOS 16.1+)
  • Launch payload: session UUID handed to Dart via HomefitLaunchChannel; SessionShellScreen lands on Camera mode
